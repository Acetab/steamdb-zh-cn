# SteamDB 简体中文界面汉化（非官方）

在 SteamDB（steamdb.info）网页上把常见界面文本改写为简体中文的浏览器扩展。**非官方项目**，与 SteamDB 网站及其官方扩展无任何关联。

## 特性

- 纯本地运行：词库随扩展分发（`translations.zh-CN.json`），运行时在页面内改写文本，**不发起任何网络请求、不上传任何数据**。
- 动态内容监听：搜索建议、表格、切换标签后异步出现的内容也会被翻译。
- 页面内浮动按钮（右下角「译」）：暂停/启用汉化、采集当前页未翻译文本、自动采集与导出。
- 自包含词库结构：`global`（全局词条）、`pages`（按路径前缀的页面词条）、`attrs`（placeholder/aria-label/title 属性词条）、`regex`（数字/日期等锚定模式）。
- 词库规模：**约 2,000+ 条**（global 1,326 / pages 11 组 684 / attrs 36 / regex 38），覆盖 SteamDB 主要固定界面文本。
- 只改写界面文本：自动跳过代码块、可编辑区、`translate=no`/`.notranslate` 内容与超长文本；不翻译游戏名和商店介绍；技术标识符（`BillingType`、`clienticon` 等代码字段）与品牌名不收入词库。

## 术语口径

优先采用 **Steam 官方简体中文译法**（参照 Steam 商店/客户端官方翻译，如 商店、库、愿望单、添加至愿望单、免费开玩、完全支持控制器、抢先体验、点数商店）；SteamDB 数据库技术对象保留社区惯用名（`SUB`、`Depot`、`AppID`）；游戏类型缩写（`FPS`、`RPG`、`PvP` 等）按社区惯例保留英文。

## 词条来源说明

词库全部为原创译文，无任何外来版权负担：

- **短词条**（如 `Monday`→星期一、`Yes`→是、`Euro`→欧元）属于事实性译法——翻译空间极小，任何译者产出都相同，不构成版权问题。
- **Steam 官方标准术语**（如「完全支持控制器」「部分支持控制器」）按 Valve 官方商店译法采用，与社区其他汉化相同属正常（都源自官方翻译）。
- **长句与短语**均为独立措辞的原创翻译，已通过自动化审计排除与既有汉化脚本雷同（长句雷同数为 0，仅官方术语除外）。
- 代码字段名（`BillingType`、`clienticon` 等）、品牌/游戏名、句子片段不收入词库。

## 安装

**油猴脚本版**（Tampermonkey / Violentmonkey）：

1. 构建（见下）得到 `build/steamdb-zh-cn-<版本>.user.js`。
2. 在油猴管理面板「添加新脚本」，把文件内容粘贴进去保存；或直接把 `.user.js` 文件拖入油猴管理页安装。
3. 打开 `https://steamdb.info/` 生效。词库内嵌在脚本内，完全自包含，不依赖任何 CDN 或远程资源。

**扩展版**（Steam 客户端内置浏览器 / Chrome）：

1. 构建（见下）或直接使用 `build/` 目录。
2. 浏览器打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 `build/` 目录。
4. 打开 `https://steamdb.info/`，页面右下角出现「译」按钮即生效。

也可把 `build/steamdb-zh-cn-<版本>.crx` 拖入 `chrome://extensions` 页面安装（开发者模式下）。

## 构建

```bash
npm run build
```

产物（均在 `build/` 目录，已 gitignore）：

| 文件 | 说明 |
|---|---|
| `steamdb-zh-cn-<版本>.user.js` | 油猴脚本版（词库内嵌，自包含） |
| `build/` | 未打包扩展目录，推荐「加载已解压的扩展程序」 |
| `steamdb-zh-cn-<版本>.zip` | 扩展分发用压缩包 |
| `steamdb-zh-cn-<版本>.crx` | 带 RSA 签名的 CRX3（首次构建生成 `keys/extension.pem`，请勿提交或泄露） |

油猴版与扩展版共用同一份引擎（`src/content.js`），词库一致；油猴版通过构建时注入的内嵌词库运行，扩展版从扩展资源读取。

## 补词流程

当前词库已覆盖主要固定界面文本，日常只需按页面微调：

1. 打开漏译较多的页面，点击「译」→「采集当前页未翻译文本」，剪贴板会得到该页未翻译候选。
2. 长期维护可开启「自动采集」，浏览多个页面后「复制当前路径采集结果」或「复制全部采集结果」。
3. 筛选候选：剔除游戏名、用户内容、品牌名后，把固定界面词条加入 `translations.zh-CN.json`：
   - 全局通用词条 → `global`
   - 特定页面词条 → `pages`（按路径前缀，如 `/app/`、`/charts/`）
   - 属性词条（placeholder/aria-label/title）→ `attrs`
   - 带数字/日期的锚定文本 → `regex`（`{ "source": "正则", "target": "替换结果" }`）
4. 重新 `npm run build`，在 `chrome://extensions` 点击扩展的刷新按钮，再刷新 SteamDB 页面。

## 词条规模与体积

当前词库约 2,000 条、紧凑 JSON 约 85KB：油猴版内嵌后脚本约 100KB（Greasy Fork / 油猴均可正常安装），扩展版约 115KB（本地资源加载无压力）。若词库未来超过 150KB，可将 `pages` 按路径拆分为独立 JSON 并按需加载（词库结构已按页面分组，拆分成本很低），届时再启用。

术语口径：优先采用 Steam 官方简体中文译法（商店、客户端内可见的译名），数据库技术标识（AppID、Sub、Depot 等）保留原文。
