# 1.0.12

漏翻采集现在提供检查窗口：勾选需要反馈的文字，填写备注，再下载 JSON、Markdown 或复制结果。窗口提供手动提交 Issue 的入口，不自动上传页面内容。

- 根据优惠、排行榜和计算器的用户采集结果新增 52 条页面及属性规则，包括筛选提示、排序提示、搜索快捷键和 SteamID 格式说明。
- 减少游戏链接、实际 SteamID、好友代码、日期和采集窗口自身文字的误采；不读取输入框的值，导出网址移除查询参数。
- 当前页重新采集时清除该路径的旧结果，避免此前误采条目继续累积。
- 油猴脚本包含当前安装词库，旧缓存不能覆盖新版本；在线来源仍由用户在油猴菜单中选择。

验证：构建和现有检查通过；隔离 Edge 测试通过采集排除、结果勾选、JSON 下载及网址参数排除。新增词条依据用户提供的真实页面文字补充，尚未逐项验证真实页面命中，公开访问 SteamDB 返回 403。Steam 内置浏览器尚未实测。
