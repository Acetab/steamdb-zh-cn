新增用户可选择的油猴词库来源。点击页面右下角“译”，选择带“词库来源”的菜单项，当前模式带勾选标记；选择后自动刷新，设置跨页面保留。

- 自动：GitHub Raw 优先，失败再请求 jsDelivr（保持旧版本默认行为）。
- 仅 GitHub：失败继续使用本地缓存，不请求 jsDelivr。
- 仅 jsDelivr：失败继续使用本地缓存，不请求 GitHub Raw；CDN 内容可能滞后。
- 仅本地词库：引擎不主动请求远程更新，使用缓存或安装词库快照。脚本安装/更新时油猴仍可能下载 @resource，脚本本身的自动更新由油猴管理。

扩展版保持打包词库、无需在线更新，不显示在线来源选择。引擎变更需更新油猴脚本或扩展安装包；仅更新词库不足以获得本次菜单。
