SteamDB 中文汉化 1.0.8 将固定界面翻译改为更保守的匹配方式，减少正文、游戏名称和数据内容误翻。

### 更新内容

- 通用文字翻译限于按钮、标签、表头、导航等界面控件；普通段落、数据单元格和主标题需明确上下文规则。
- 新增控件上下文词库，按控件规则、页面词典、通用词典顺序匹配，原文未命中则保持不变。
- 单文字节点和属性保留原文记录，历史导航及页面恢复后重新匹配对应译法。
- 修复动态扫描漏掉根控件 title、aria-label、placeholder 的问题。
- 加强游戏/软件链接、用户内容及编辑区保护，新增上下文审计和回归检查。

### 安装与更新

- 油猴用户：安装附件 `.user.js` 更新同名脚本。仅更新远程词库不能获得本次引擎修复。
- 本地扩展用户：下载 ZIP，解压到持久目录，通过“加载已解压的扩展程序”安装；已有安装可更新原目录内容后重新加载扩展。CRX 为备选安装包，浏览器可能限制直接安装。
- 扩展词库随包发布；油猴词库仍支持缓存与多源更新。不要同时启用扩展版和油猴版。

### 验证与限制

构建、语法、启动和上下文/属性回归检查通过；隔离 Edge 页面验证了匹配优先级、页面往返重新匹配及输入值保护。未在 Steam 客户端实测。规则收紧后部分界面可能漏翻，应通过定向上下文规则补充；尚无通用 Shadow DOM 翻译支持。

设计参考 GitHub 汉化项目的页面规则、动态处理及控件保护思路，本次未复制其源码或词库。
